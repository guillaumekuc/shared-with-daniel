# How we work (training wheels mode)

No rules yet. Everyone works directly on `main`.

1. **Pull** before you start.
2. Make your changes.
3. **Stage** → **Commit** (with a short message) → **Push**.

Same thing on the command line: `git pull`, then `git add .`, `git commit -m "..."`, `git push`.

New to all this? Start with [COMMENCER-ICI.md](COMMENCER-ICI.md) (FR) or [START-HERE.md](START-HERE.md) (EN).
